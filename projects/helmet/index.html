OpenClaw Skill for Finland's Helmet Library

An OpenClaw SKILL for the Finnish public library Helmet (Helsinki Metropolitan Area libraries). With it, you can ask your OpenClaw agent from WhatsApp: “Is anything overdue for the kids at the library?” or “Place a hold on AI Engineering by Chip Huyen”.

Demo

Why

I had recently set up OpenClaw and wanted it to simplify my daily life. My kids and I read a lot of books, and we borrow them from Helmet.

Helmet had no CLI or API to manage your library account. It has an open API to search books, but nothing for loans, holds, or fines. So I built the Helmet CLI first, and then a SKILL so that my OpenClaw agent can use it.

What the CLI does

  • Check loans, and renew one item or all renewable items.
  • List, place, and cancel holds, with pickup deadline and queue position.
  • Show fines and a full account summary.
  • Search the Helmet catalog without a login.
  • Keep several library cards as profiles, so one command can cover the whole family.

Every command accepts --json, which makes the output easy for an agent to read.

Install

Install the CLI from npm, then save a library card:

npm install -g @helmet-ai/helmet
helmet login

Install the SKILL from ClawHub, or with the skills CLI:

npx skills add vijaykodam/helmet
