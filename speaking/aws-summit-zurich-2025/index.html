Autonomous Troubleshooting on Amazon EKS with Strands Agents and MCP

AWS Summit Zurich 2025 · Zurich, Switzerland · 11 September 2025

linkedin post →

At AWS Summit Zurich I shared a view of where cloud operations is heading, along with an end-to-end demo: autonomous troubleshooting on Amazon EKS with Strands Agents and the Model Context Protocol.

Kubernetes troubleshooting has been automated for years. What is changing is that it is becoming autonomous. An agent can now hold enough context about a cluster to investigate a problem, not just execute a fixed runbook against it.

That shift is early, and this demo was one data point rather than a finished product. But agentic systems and open protocols like MCP are going to reshape how cloud operations works, and they move us closer to infrastructure that recovers on its own.
